Integrations

Systems this can connect to, with their published APIs and GitHub SDKs

Guiding principle: the client didn't want dramatic change. The existing pipeline of mandates gets delivered first. Anything new is added only where it helps that delivery, and strategic change waits until the pipeline is complete. It's tested with the client and adjusted in the first week.

The figures in the review come from job, invoice, payment, plant and supplier data. These are the systems that data normally lives in, and each one has a published API, so it can be read automatically rather than re-keyed. Where the vendor publishes code on GitHub, it's linked.

Nothing here is connected in the demo. The invoice reader already produces Xero's bill-import format, so Xero would be the first live connection, followed by whichever job, plant and stock systems are actually in use.
